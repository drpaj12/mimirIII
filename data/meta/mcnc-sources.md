# Sources for mcnc.toml

Checked 2026-10-27. "Verified" means: DOI resolved against the Crossref API (title, venue, year, pages, authors compared). DBLP was not queried. Items with no DOI are marked so. Downloads were kept under /tmp/claude-1000/mim-meta-*/ and treated as data; nothing from them was executed. Text was pulled from PDFs with a small local script and by decompressing the 7z container in memory.

Source ids used in `mcnc.toml`:

## yang91 (primary)
- URL: https://ddd.fit.cvut.cz/www/prj/Benchmarks/LGSynth91.pdf (also LGSynth91.bib on the same site)
- Note: S. Yang, "Logic Synthesis and Optimization Benchmarks User Guide Version 3.0", MCNC, 1991-01-15, 45 pp. Extends the v2.0 guide by Lisanke (Dec 1988). Tables: s3.1 FSM (pp.6-7), s3.2 sequential multi-level (pp.8-9, footnote on p.9), s3.3 combinational multi-level (pp.10-11), s3.4 two-level (pp.12-13), s1 acknowledgements (p.2). Page numbers are the printed ones, read from extracted text; some glyphs were dropped by extraction, so a few names (apex2, apex4, pdc, ex5p) in the two-level table were matched by I/O and term counts.
- This is also what the VTR docs cite as `mcnc_benchmarks` (Yang 1991) and what Hutton cites as [74].

## lgsynth91-7z (primary; archive members)
- URL: https://ddd.fit.cvut.cz/www/prj/Benchmarks/LGSynth91.7z (2.9 MB). Member listing and member text read in memory.
- Used for: file names and formats per circuit (pla/, blif/, kiss2/, slif/, Verilog/); `slif/README` (Stanford; hlexamples = "10 SLIF files corresponding to high level benchmarks of the HL synthesis workshop suite"; pattern files "generated by hand for the high level examples"); `.date` lines in the SLIF files (Jan 1991); pattern-file comments for diffeq, elliptic ("elliptic filter input patterns"), frisc (assembly program, pc, stack, interrupt service); `.model s38584.1.bench` and `.model s298.bench` in blif/. Members `LGSynth91.readme`, `LGSynth-doc.pdf` (the guide).
- Not a bib item (data distribution). The original FTP location named in its readme is mcnc.mcnc.org:/pub/benchmark/LGSynth91, now offline.

## hutton97 (secondary)
- Local: work/mimir-papers/MichaelHutton.pdf (relative reference, read only). M. D. Hutton, "Characterization and Parameterized Generation of Digital Circuits", Ph.D. thesis, Dept. of Computer Science, University of Toronto, 1997. Table 4.2 (p.55) gives one-line descriptions: elliptic "elliptic eqn solver", dsip "encryption", bigkey "key encryption", tseng "bus-controller", dieq "differential eqn solver", s298 "fsm from a PLD".

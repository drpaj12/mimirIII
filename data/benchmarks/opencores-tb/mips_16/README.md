# mips_16 testbench

tb_origin: `mimir-written` (`tb_mips_16.v`, `gen_mips_programs.py`, generated `.prog` / `.exp` files, Mimir
repo licence). The RTL (`rtl/*.v`; the project states no licence) and the project's `test2.prog` are not copied
here. The project's bench (`mips_16_core_top_tb_0.v`) prints registers and checks nothing; its R3 = 476 is
checked here.

Programs, loaded with `$readmemb` into `uut.IF_stage_inst.imem.rom` as the project's bench does; after reset
and a fixed run (700 clocks for test2, 120 for the others) R0..R7 and data memory words 0..7 are compared
(34 checks, `PASS tb_mips_16 checks=34 errors=0`):
- `test2` (copy `bench/mips_16_core_top/test2.prog` of the project into the run directory): multiply
  28 * 17; expected R3 = 476, R5 = 16, R6 = 1, R7 = 16, R1 = R2 = R4 = 0, from reading `test2.asm` (hand-derived).
- `alu`, `shift_mem`, `dependent`: expected values from an independent Python model of the instruction set
  in `doc/instruction_set.txt` (`gen_mips_programs.py`: assembler + model; ADDI, ADD, SUB, AND, OR, SL, SR
  arithmetic, SRU, ST, LD, and back-to-back dependent instructions with no NOP gaps). The `.prog` files are
  generated by the assembler; the stop loop is the one of test2 (`BZ R0,-1`, NOP).
A mutation (SUB made ADD in `alu.v`) gives FAIL with 7 errors. No branch is tested beyond the stop loop and
test2's own loops.

Findings, observed not fixed:
1. `ID_stage.v` sets `alu_src2_mux = 1'bx` for `OP_XOR`, so the second XOR operand is x in iverilog (result
   `00XX`) and unspecified in a 2-state simulator. XOR is therefore not part of the checked programs; the
   `xor` program is run and its R3 printed as an `INFO` line.
2. The core prints `ERROR: Unknown Instruction: xxxx` at reset time (instruction ROM word x before the
   first load); harmless in these runs.

Run (iverilog), in a directory with all `rtl/*.v`, `tb_mips_16.v` and the `.prog` / `.exp` files plus
`test2.prog`:

    python3 gen_mips_programs.py .      # or use the committed files
    iverilog -g2005 -I . -s tb_mips_16 -o sim.vvp *.v && vvp sim.vvp

Odin III: refused, `tb_mips_16.v:15: unsupported: compiler directive` (`include`; the bench also writes the
ROM through a hierarchical path, outside the sim_tb subset).
